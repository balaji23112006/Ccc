What is the Travelling Salesman Problem?

🌐

The Problem

Given a set of n cities and the distances between every pair, find the shortest possible route that visits each city exactly once and returns to the starting city. This closed loop is called a Hamiltonian cycle.

🔥

Why It's Hard

TSP is NP-hard — a brute-force search requires evaluating (n−1)!/2 possible tours. For just 20 cities that's over 60 quadrillion routes. Smart algorithms are essential.

🚀

Real-World Impact

From logistics and delivery routing to circuit board drilling and genome sequencing, TSP appears everywhere. Solving it efficiently saves time, fuel, and resources.

Dynamic Programming Held-Karp Approach

01

State Representation

Define dp[S][i] as the minimum cost to visit all cities in the subset S, ending at city i. The subset S is encoded as a bitmask of n bits.

02

Base Case

dp[{0}][0] = 0 — start at city 0 with zero cost. All other states are initialised to ∞.

03

Transition

For each subset S and each city j ∈ S, try extending from every city i ∈ S where i ≠ j:
dp[S][j] = min(dp[S \ {j}][i] + dist[i][j])

04

Answer

The optimal tour cost is min over all i of (dp[ALL][i] + dist[i][0]), closing the cycle back to the origin.

held_karp.py 
def tsp_dp(dist):
    n = len(dist)
    ALL = (1 << n) - 1
    dp = [[float('inf')] * n
          for _ in range(1 << n)]
    dp[1][0] = 0

    for S in range(1 << n):
        for j in range(n):
            if not (S >> j & 1):
                continue
            for i in range(n):
                if i == j:
                    continue
                if not (S >> i & 1):
                    continue
                prev = S ^ (1 << j)
                dp[S][j] = min(
                    dp[S][j],
                    dp[prev][i] + dist[i][j]
                )

    return min(
        dp[ALL][i] + dist[i][0]
        for i in range(n)
    )
